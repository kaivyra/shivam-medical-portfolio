Roadmap

What is not built yet

These are planned, not operational. They are listed so the platform is honest about its current scope.

3D Anatomy Not built

Interactive 3D models need licensed or openly licensed assets and a rendering pipeline.

Medical Knowledge Graph Not built

Requires a normalized concept database (for example MeSH/UMLS) and curation.

Global Research Community Not built

Requires accounts, moderation and a privacy policy for user content.

Institutional Research Portals Not built

Requires multi-tenant accounts and access control.

Multilingual Medical Intelligence Not built

Requires translation review for medical accuracy.

Interactive Medical Learning Not built

Courses and assessments need editorial review.

Advanced Research Agents Not built

Requires a generative model and an evaluation set; not enabled.

Semantic search and paper database Not built

Needs PostgreSQL schema, embeddings and pgvector.

User accounts and cloud-synced workspace Not built

Needs server-side authentication and authorization.

Editorial and data management console Not built

Evolves the existing owner content manager.

PubMed E-utilities, Crossref, OpenAlex, WHO data Not built

Europe PMC (which indexes PubMed) and ClinicalTrials.gov are connected now.
